# Vídeos da Sprout

Coloque os oito vídeos nesta pasta. Prefira MP4 com vídeo H.264 e áudio AAC para compatibilidade com navegadores. WebM também é aceito; outros formatos precisam ser convertidos antes.

Sugestão de nomes: video-01.mp4 até video-08.mp4. Os arquivos são descobertos automaticamente e ordenados numericamente pelo nome. Reinicie a prévia após adicionar os arquivos; em hospedagem é necessário gerar e publicar uma nova versão.

Cada arquivo substitui um espaço reservado. Os vídeos têm controles, reprodução no próprio cartão e não iniciam automaticamente. preload="metadata" e posicionamento em 0,01 segundo carregam o quadro inicial antes do play, sem reprodução automática. O enquadramento usa contain para preservar o vídeo completo, inclusive se for horizontal.

Esta pasta é pública: coloque apenas os arquivos que devem aparecer no site. Títulos, capas e legendas podem ser ajustados após a revisão do conteúdo.

Os oito vídeos atuais têm as faixas de áudio removidas; originais com áudio permanecem na pasta Imagens de Referncias da raiz. scripts/remove-video-audio.mjs permite repetir a remoção em MP4 não fragmentado.
